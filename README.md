## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина с формой заявки, модальным окном, карточками товаров и фильтрами.

## Реализованные страницы

### Главная (`index.html`)

- hero-блок с приветствием и кнопкой перехода к товарам;
- секция «Преимущества проекта»;
- секция «Популярные товары» с сеткой карточек;
- блок FAQ;
- блок «Информация для студентов»;
- модальное окно с формой заявки.

### Каталог (`catalog.html`)

- хлебные крошки;
- sticky-блок фильтров;
- сетка из 6 карточек товаров;
- модификаторы карточек.

### Карточка товара (`product.html`)

- хлебные крошки;
- подробное описание, цена, кнопка «Оформить заявку»;
- таблица характеристик.

### Заявка (`order.html`)

- хлебные крошки;
- форма заявки как отдельная страница;
- валидация через HTML-атрибуты;
- сообщение об успешной отправке.

### Контакты (`contacts.html`)

- хлебные крошки;
- контактные данные (телефон, e-mail, адрес);
- ссылка на страницу заявки.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.

## Использование Flexbox и Grid

В проекте используются:

- **Flexbox**:
  - меню навигации;
  - внутренняя структура карточек товара;
  - блок кнопок формы.

- **CSS Grid**:
  - сетка карточек товаров;
  - страница каталога с фильтрами и списком;
  - карточка товара: медиа + описание.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `product-detail` — подробная карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка;
- `success-message` — сообщение об успешной отправке;
- `faq` — блок частых вопросов;
- `scroll-top` — кнопка «Наверх».
